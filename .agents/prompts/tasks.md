# Employee App Tasks
## 1. Add Employee & Employee List Feature
I want you to implement Add Employee and Employee List feature. Below are the detailed requirement
Employee List: All the employees should be displayed in a react component table. The employees should be sortable by column. For each employee you must store/show following fields: Employee ID, Full Name, Gender, Date of Joining, Email, Phone Number. Employee list should be the first thing anyone sees post they login.

Add Employee: There should be a button at the top of Employee List in a nice row wherein we can add more action buttons in the future. The click of Add Employee button must open a nice Modal to enter the information needed to add an employee. Every field apart from Full Name and Email should be optional. Employee ID should be auto-generate with prefix 'FSD-'. Date of Joining should be in the future or not more than 15 days in the past. Gender should be a group of radio-buttons.
